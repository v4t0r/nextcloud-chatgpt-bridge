# Terms and service boundary

These terms describe the intended source and hosted-service boundary. A public operator must obtain
appropriate legal review and publish operator-specific terms before accepting hosted accounts.

## Open-source software

The repository is licensed under Apache License 2.0. The license governs copying, modification, and
distribution of the source. It does not promise a hosted service, uptime, support level, OpenAI
approval, or compatibility with every Nextcloud deployment.

## Hosted service scope

When separately offered, the service lets an authenticated user connect a Nextcloud account and ask
ChatGPT or Codex to perform bounded operations inside a selected workspace root. Users remain
responsible for their Nextcloud account, selected root, files, permissions, backups, prompts, and
confirmation of destructive changes.

The service is not an all-access Nextcloud administrator, payment system, accounting system, tax
advisor, legal advisor, backup provider, or emergency service. Invoice review is decision support
only and cannot approve, book, pay, transmit, or automatically archive an invoice.

## Acceptable use

Users must not use the service to access data without authorization, evade technical boundaries,
distribute malware, probe other tenants, overload infrastructure, or violate applicable law or third-
party rights. Operators may rate-limit, suspend, or terminate access needed to protect users and the
service.

## Account connection and deletion

Connection uses Nextcloud Login Flow v2 and creates a Nextcloud app password. Disconnect removes
local connection state and attempts remote revocation. Users should verify revocation in Nextcloud
when the remote server was unavailable and retain independent backups of important data.

## Availability and changes

Beta software may change, be interrupted, or contain defects. Operators must publish material hosted
service changes and their effective dates. Source releases and OpenAI directory approval are separate;
a repository tag does not guarantee that public hosted access is available.

## Warranty and liability

The open-source software is provided under the warranty and liability terms of Apache License 2.0.
Any public operator must publish jurisdiction-appropriate hosted-service warranty, liability,
consumer-rights, governing-law, and dispute terms before launch.

## Contact

Security issues belong in GitHub private vulnerability reporting. The public operator must add a
non-security support and legal contact before accepting hosted accounts.
