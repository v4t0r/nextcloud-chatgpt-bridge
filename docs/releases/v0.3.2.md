# v0.3.2 — submission recovery and provider roadmap

Maintenance release for the existing Files and household-invoice bridge. No new Talk, calendar,
contacts or administrative permissions are introduced in this release.

- Build a complete portable directory ZIP with explicit remote MCP and predefined OAuth settings,
  the verified publisher name, legal links, icon and workspace skill.
- Preserve the existing directory identity and use directory package version 1.0.1 independently
  of Python/runtime version 0.3.2. The legacy portal ZIP 1.0.0 contained only metadata.
- Explicitly enable MCP resource-token validation alongside the existing pinned JWT audience check.
- Refresh supported dependencies, upgrade the container's pip and apply available distribution fixes.
- Exclude original local MOV recordings from Git and source distributions.
- Define staged delivery and acceptance gates for v0.4 Talk, v0.5 groupware and later app providers.

An uploaded ZIP or a GitHub release does not imply OpenAI approval or public availability.
See the dated submission checkpoint for actual portal and deployment results.
