# v0.3.1 — hardened deployment beta

This release supplies a reproducible single-VM deployment behind Nginx Proxy Manager, with a
separate Keycloak provider and PostgreSQL stores. It adds a guarded Ubuntu bootstrap, private
runtime initialization, key-only SSH and Docker-aware ingress rules with automatic rollback.

Container resource limits, bounded logs, a non-root/read-only Caddy edge, OAuth request/queue
limits and patched Caddy Go dependencies reduce the deployment attack surface. Existing tenant,
workspace, token and validated-egress boundaries remain in place. Expected tool errors now use
the MCP SDK's explicit ToolError type instead of being hidden as unexpected failures.

Read `docs/SINGLE_VM_DEPLOYMENT.md` and `docs/SECURITY_HARDENING.md` before deploying. Back up both
databases and keep runtime secrets outside Git. The hardening script is for a dedicated VM and
requires verified SSH key access and an explicit administration subnet.

This is a source release, not an OpenAI approval or a claim of vulnerability-free operation.
Unresolved upstream image findings require deployment-specific assessment. In particular, verify
the NPM fix for CVE-2026-40519; version 2.15.1 alone does not prove that fix is present.
OAuth login, two-tenant hosted acceptance, reviewer fixtures, publisher/legal alignment and
domain proof must be completed before submission. See `submission/FINAL_CHECKLIST.md`.
